# SokoBoulder 0.1.3

Kurze Installationshilfe für den ersten macOS-Start.

- DMG-Hintergrund erklärt die Installation nach „Programme“ und die macOS-Freigabe.
- README und START-HERE.txt erklären den Dialog „Apple konnte nicht überprüfen …“ Schritt für Schritt.
- Das Retro-HUD aus 0.1.2 ist enthalten.

## Installation und erster Start

Für macOS 14+, Apple Silicon und Intel. DMG öffnen und SokoBoulder nach
„Programme“ ziehen; alternativ das ZIP entpacken und die App dorthin verschieben.
Die App anschließend aus „Programme“ starten.

SokoBoulder ist eine quelloffene Demo, die du selbst bauen kannst. Für dieses
Projekt verzichten wir auf ein kostenpflichtiges Apple-Entwicklerkonto und damit
auf die Notarisierung.

Falls macOS beim ersten Start „Apple konnte nicht überprüfen …“ meldet:

1. **Fertig** klicken.
2. **Systemeinstellungen → Datenschutz & Sicherheit → Sicherheit → Dennoch öffnen** wählen.
3. Mit **Öffnen** bestätigen.
