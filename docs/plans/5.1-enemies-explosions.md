## Scope

- Glühwürmchen (`F`) und Schmetterlinge (`B`)
- Explosionen `destructive` / `diamondGenerating` + Ketten-Queue
- Stahlwand wirklich unzerstörbar; Ausgang im MVP ebenfalls unzerstörbar
- ASCII/JSON, Digest, Render-Fallback (Shapes), Explosion-Event

**Nicht in 5.1:** Amöbe, Magische Wand, Arcade-Leben, Sand (4.1), Pixel-Sprites für Gegner (Shapes reichen)

## Tick-Reihenfolge (nach ADR, Implementierung)

1. Spieler  
2. **Explosions-Queue drain** (+ Early-Exit bei Tod)  
3. Gravity (Fels/Diamant)  
4. **Explosions-Queue drain** (+ Early-Exit)  
5. Gegner (simultane Intents) — **nur `tick % 2 == 0`** (halbe Rate)  
6. **Explosions-Queue drain** (+ Early-Exit)  
7. Exit öffnen / Abschluss  
8. Zeit  

Nicht „eine Queue erst am Tickende“: Drain pro Phase hält Tod vor weiterer Physik.
Neu erzeugte Diamanten aus Butterfly-Explosionen handeln erst ab dem **nächsten** Tick.

## Modell

```swift
case firefly(EntityID, heading: Direction)
case butterfly(EntityID, heading: Direction)
```

Glyphs: `F` / `B` auf Floor. Start-`heading` default `.left`.

## Bewegung

Nur Leerraum (`.empty`) oder Spielerzelle (Kontakt → Explosion + Tod).

Klassische BD-Fly-AI (kein Wand-Seek, kein Pivot):

- Firefly: links frei → drehen+bewegen; sonst vorne; sonst rechts drehen **ohne** Move  
- Butterfly: rechts bevorzugt (sonst analog)  
- Offener Raum: 2×2-Orbit ist spezifikationskonform  

Scan Intent oben→unten, links→rechts. Zielkonflikt: früher Intent gewinnt; Verlierer bleibt (Position+Heading unverändert).

## Explosion

3×3 um Zentrum. Queue, nicht rekursiv. FIFO; Überlapp = letzter Schreiber.

| Zelle | destructive | diamondGenerating |
| --- | --- | --- |
| `steelWall` / `exit` / `void` / OOB | unverändert | unverändert |
| sonst | Terrain → `floor`, Occupant weg | wie links, plus ruhender Diamant |

Weitere Gegner in der Fläche → deren Explosion enqueuen (Kettenzelle bekommt keinen Diamanten vom Eltern-Blast). Spieler in Fläche → Tod.

Auslöser: Spieler betritt Gegner, Gegner betritt Spieler, fallender Fels/Diamant trifft Gegner (Impakt belegt die Zelle, Explosion zerstört inkl. Impakt-Objekt).
