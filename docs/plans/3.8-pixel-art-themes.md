# Plan 3.8: Pixel-Art-Themes (Dungeon + Kenney)

Status: Umgesetzt (Playtest / Untermaß-Release-Gate noch offen)
Datum: 2026-08-03
Hinweis: Früherer Dateiname `3.8-pixel-art-vellidragon.md` (Asset-Kandidat verworfen).

## Ziel

Zwei Pixel-Brett-Themes mit Settings-Umschaltung; Vektor (`theme.standard`) bleibt
Code-Fallback / Dev-Switch und bricht ADR 0003 nicht.

## Themes

| ID | Rolle | Quellen |
|----|--------|---------|
| `theme.dungeon` | **Default** — Custom-Mix | Floor cobble (CC0), Wall stone (CC-BY-SA 3.0), Player (CC-BY 3.0), Crate (CC0), Goal glow (CC0) |
| `theme.kenney` | Zweites Theme | [Sokoban 100 Tiles](https://opengameart.org/content/sokoban-100-tiles) (Kenney, CC0) |
| `theme.standard` | Nicht in Settings | Built-in / `DevVisualThemeSwitch.forceVectorStandard` |

## Vertrag (fest)

| Punkt | Entscheidung |
|--------|----------------|
| Default | `theme.dungeon` |
| Settings | Picker mit Dungeon + Kenney |
| Fallback | `theme.standard` / `BuiltInThemes.standard` nur bei Load-Fehler |
| Dev-Switch | `DevVisualThemeSwitch.forceVectorStandard` (DEBUG) |
| Blick | **bird’s-eye** |
| Basis | **64×64** Texturen; `baseTilePoints` nur Authoring-Hinweis |
| Max-Scale | entfällt — Pixel füllt kontinuierlich + `.nearest` |
| Schema | **V1 additiv**: optionales `rendering`; fehlend = Vektor-Verhalten |
| Profil-ID | `pixelNearest` (Legacy-Alias `pixelInteger` beim Decode) |
| Fehlende/kaputte Textur | Theme ungültig → **pro bekannter ID** Skip; Catalog bleibt ladbar |
| Entity-Inset | im Pixel-Profil **0** |
| Feedback-Symbole (×/✓) | bleiben als Overlay auf `effectLayer` |
| Brett-Symbole / Strokes | im Pixel-Profil aus |
| Lizenz | `THIRD_PARTY_NOTICES.md` + SHA + `Textures/Licenses/` |

## Architektur

```text
theme.dungeon.json ─┐
theme.kenney.json  ─┼─► ThemeCatalogLoader ──► VisualTheme
                    │                              │
                    │                              ├─► SokobanBoardScene
                    │                              └─► GridGeometry
Textures/{dungeon,kenney}/*.png ──────────────────► SokobanBoardScene

GridGeometry:
  vectorContinuous → stufenlose tileSize (ADR 0003)
  pixelNearest     → dieselbe tileSize-Formel; Darstellung via nearest/Inset 0
```

Profil steuert nur Darstellung (Texturen / Inset / Filter). Kein GameCore-Impact.
Branches immer über `rendering.profile`, nie über hardcodierte `themeID`.
